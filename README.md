# FPV 1-1

The most famous first level in gaming, rebuilt block by block as original voxel art — playable in first person, on foot or as an FPV drone.

**Play: https://fpv-1-1.pages.dev**

- Run mode: WASD + mouse, Space jump, Shift sprint. Bump ? blocks, grab coins, stomp grumblers, reach the flag.
- Drone mode (F): fly the level FPV-style — Space up, C down, Shift boost, camera roll + FOV kick.
- Three.js, zero game assets: every texture is drawn procedurally at runtime; all sound is synthesized WebAudio.
- Touch controls on mobile.

100% original fan homage. Not affiliated with Nintendo.
